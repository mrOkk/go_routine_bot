# Таблица кейсов первой версии

Сценарии основаны на [требованиях в README](README.md#требования). Действие включает исходные условия, если они влияют на результат. В колонке «Что возвращается» можно указать, что получает пользователь и кому ещё бот отправляет уведомление. В последней колонке укажите, что меняется после действия, или напишите «без изменений».

## Доступ и приглашения

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Бот запущен с пустым или незаданным списком менторов. Любой пользователь, в том числе ранее зарегистрированный ученик, обращается к боту. | Ошибка «Пользователь с id {id} не зарегистрирован, обратитесь к владельцу бота». В сообщении указан Telegram ID отправителя. | Состояние не меняется. |
| Пользователь, чей id прописан в переменных окружения впервые открывает бота | Бот приветствует ментора, показывает стандартный интерфейс ментора | пользователь регистрируется, как ментор |
| Ментор отключил бота и затем снова включил его. Его ID по-прежнему в списке. | Снова доступен интерфейс ментора без приглашения. | Роль ментора сохраняется. |
| Ментор открывает действующую ссылку для ученика в том же экземпляре бота. | Ему доступна только роль ментора. | Регистрации ученика не происходит, ссылка остаётся действующей. |
| Случайный пользователь открывает бота | Ошибка "Пользователь с id {id} не зарегистрирован" | состояние не меняется |
| Ментор создаёт отдельные приглашения для нескольких учеников. | На каждый запрос бот выдаёт новую уникальную одноразовую ссылку. | Каждая ссылка действует независимо. Количество приглашений не ограничено. |
| Новый пользователь открывает бота по действующей ссылке. | Бот приветствует ученика, говорит, кто его ментор, открывается меню ученика | Пользователь регистрируется как ученик ментора, выдавшего ссылку. Ссылка использована |
| Два новых пользователя одновременно открывают одну действующую ссылку. | Один получает доступ ученика, второй — сообщение «Недействительная ссылка». | Зарегистрирован ровно один ученик. Ссылка использована. |
| Одну действующую ссылку открывают активный ученик и новый пользователь. Первым обработано обращение активного ученика. | Активный ученик сохраняет прежний доступ. Новый пользователь успешно регистрируется. | После первого обращения ссылка ещё действительна. Её расходует регистрация нового ученика. |
| Новый пользователь открывает бота по ссылке с неизвестным идентификатором. | Ошибка "Недействительная ссылка" | состояние не меняется |
| Новый пользователь открывает бота по уже использованной ссылке. | Ошибка "недействительная ссылка" | состояние не меняется |
| Пользователь с активным доступом (далее ученик) возвращается в бот без ссылки. | Открывается интерфейс ученика | состояние не меняется |
| Ученик проходит по ссылке от другого ментора. | Бот пишет, что вы уже зарегистрированы у другого ментора, для смены ментора обратитесь к администратору | состояние не меняется |
| Ученик самостоятельно отключается. | Бот становится недоступен | Ученик становится неактивным, весь учебный прогресс сбрасывается. Его прежние работы больше не ожидают проверки |
| Отключённый пользователь пытается воспользоваться ботом без новой ссылки. | "Пользователь с id {id} не зарегистрирован" | состояние не меняется |
| Отключённый пользователь открывает новую ссылку от прежнего ментора. | Бот приветствует ученика, говорит, кто его ментор, открывается меню ученика | Ученик начинает обучение заново у ментора, выдавшего ссылку |
| Отключённый ученик открывает новую ссылку от другого ментора. | Бот приветствует ученика, говорит, кто его ментор, открывается меню ученика | Ученик начинает обучение заново у ментора, выдавшего ссылку |
| Ментор удаляет своего ученика. | Пользователю приходит сообщение, что его обучение остановлено, за поддержкой обратитесь к администратору. Бот становится недоступен | Ученик становится неактивным, весь учебный прогресс сбрасывается. Его прежние работы больше не ожидают проверки |

## Учебный план и навигация

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Ученик впервые открывает учебный план после регистрации. | Выдается список тем. Текущая тема отмечена желтым | Состояние не меняется |
| В теме есть задача в статусе «НЕ РЕШЕНА». Ученик запрашивает текущую задачу. | Открывается задача из текущей темы, на которой стоит указатель. Если пользователь не выбирал задачу, открывается первая задача в статусе «НЕ РЕШЕНА», если такая есть | Состояние не меняется |
| Ученик открывает тему с практикой, в которой ни одна задача не имеет статуса «НЕ РЕШЕНА». | Открыть текущую задачу нельзя. Список задач со статусами доступен. | Статусы задач сохраняются. |
| Ученик запрашивает текущую задачу в теме без практических задач. | Сообщение, что в этой теме не предусмотрена практика | Состояние не меняется |
| Ученик запрашивает список задач текущей темы со статусами. | Выдается пронумерованный список задач со статусами и указателем текущей задачи | Состояние не меняется |
| Ученик переходит к следующей или предыдущей задаче, когда такая задача есть. | Отображается текст задачи, для задачи в статусе «НЕ РЕШЕНА» можно прикрепить файл `.go` | Указатель активной задачи для ученика сдвигается |
| Ученик пытается перейти назад с первой задачи или вперёд с последней. | Переход недоступен | Состояние не меняется |
| Ученик возвращается к ранее открытой теме, где уже выбирал задачу и есть задачи в статусе «НЕ РЕШЕНА». | Пользователю доступны все задачи темы, указатель стоит на первой задаче в статусе «НЕ РЕШЕНА» | Указатель переводится на первую задачу в статусе «НЕ РЕШЕНА» темы |
| Ученик пытается перейти в ещё закрытую тему. | Переход недоступен | Статус не меняется |

## Сдача и проверка решений

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Ученик прикрепляет файл `.go` для задачи в статусе «НЕ РЕШЕНА». | Бот показывает статус «НА ТЕСТИРОВАНИИ». Ученик может выбрать другую задачу. | Бот сохраняет исходный код из файла и запускает автопроверку. |
| Ученик отправляет для задачи в статусе «НЕ РЕШЕНА» решение в неподдерживаемом формате. | Статус "НА ТЕСТИРОВАНИИ", можно выбрать другую задачу | Текст решения сохраняется в базе и начинаются проверки. Проверка не проходит, устанавливается статус "НЕ РЕШЕНА", отправляется сообщение ученику |
| Ученик повторно отправляет решение задачи в статусе «НА ТЕСТИРОВАНИИ», «НА ПРОВЕРКЕ» или «РЕШЕНА». | Отправка недоступна. | Статус и ранее отправленное решение сохраняются. |
| Решение собралось, запустилось и выдало ожидаемый результат за отведённое время. | Пользователю приходит обновленный статус задачи | Статус меняется на "НА ПРОВЕРКЕ", пользователю отправляется сообщение |
| Решение не удалось собрать. | Пользователю приходит обновленный статус задачи | Статус меняется на "НЕ РЕШЕНА", пользователю отправляется сообщение |
| Решение собралось, но не запустилось, выдало неверный результат или превысило лимит времени. | Пользователю приходит обновленный статус задачи | Статус меняется на "НЕ РЕШЕНА", пользователю отправляется сообщение |
| Автопроверка прервалась из-за технического сбоя. | Статус задачи "НЕ РЕШЕНА". Ученик может повторно отправить решение. | Задача снова доступна для сдачи в статусе «НЕ РЕШЕНА». |
| Ментор открывает работу из списка на проверку. | Ему выдается код решения | Состояние не меняется |
| Ментор принимает работу без комментария. | Открываются доступные для проверки задачи | Статус задачи меняется на "РЕШЕНА", ученику отправляется сообщение с новым статусом |
| Ментор принимает работу с комментарием. | Открываются доступные для проверки задачи | Статус задачи меняется на "РЕШЕНА", ученику отправляется сообщение с новым статусом и сообщением от ментора |
| Ментор отклоняет работу с комментарием. | Открываются доступные для проверки задачи | Статус задачи меняется на "НЕ РЕШЕНА", ученику отправляется сообщение с новым статусом и сообщением от ментора |
| Ментор пытается отклонить работу без комментария. | Ошибка "для отклонения нужна причина" | Состояние не меняется |

## Тесты и открытие тем

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Ученик начинает тест текущей темы. Активной попытки нет. | Бот показывает первый вопрос. | Попытка активна, указатель стоит на первом вопросе. |
| Ученик вернулся к активному тесту после перерыва, например через месяц. | Бот показывает тот вопрос, на котором ученик остановился. | Попытка, её ответы и позиция сохраняются. |
| Ученик явно вышел из незавершённого теста и позже начал его снова. | Бот показывает первый вопрос. | Прежняя попытка прервана. Начата новая попытка без ответов. Лучший результат завершённых попыток сохраняется. |
| Ученик выбирает один из четырёх вариантов ответа на вопрос. | Ответ принимается, открывается следующий вопрос | Ответ записывается, указатель активного вопроса сдвигается |
| Ученик завершает тест. | Бот показывает процент правильных ответов и отмечает результат по каждому вопросу. Если открылась следующая тема, бот сообщает об этом отдельно. | В прогрессе сохраняется лучший процент среди завершённых попыток. Если он выше или равен порогу (100% в первой версии), тест засчитывается. Зачёт сохраняется окончательно. Если это тест последней доступной темы, он зачтён и все задачи до следующей темы имеют статус «НА ПРОВЕРКЕ» или «РЕШЕНА», следующая тема становится доступной, если она есть в плане. |
| Ученик пытается повторно пройти непройденный тест. | Тест запускается с начала. | Указатель теста устанавливается на первый вопрос |
| Одна из предыдущих задач ещё «НА ТЕСТИРОВАНИИ». Все остальные условия для открытия новой темы выполнены. | Новая тема пока закрыта. | Доступ к темам не меняется. |
| Последняя из требуемых задач перешла в «НА ПРОВЕРКЕ». Остальные условия открытия следующей темы уже выполнены. | Ученик получает отдельное сообщение об открытии следующей темы. Тема уже доступна в плане. | Тема открывается автоматически. Текущая тема ученика сохраняется. |
| Последняя доступная тема содержит только теорию. Все более ранние задачи на проверке или решены, но ученик ещё не получил ссылку на теорию этой темы. | Следующая тема пока закрыта. | Состояние не меняется. |
| В тех же условиях ученик получает ссылку на теорию этой темы. | Ученик получает ссылку на теорию и отдельное сообщение об открытии следующей темы. | Получение ссылки отмечено. Следующая тема открыта, текущая тема сохраняется. |
| Ученик переходит в автоматически открывшуюся тему. | Бот выдаёт ссылку на теорию и показывает предусмотренные темой задания. | Выбранная тема становится текущей. Если в ней есть задачи, указатель переключается на задачу этой темы. |
| Ученик пытается открыть новую тему при незачтённом тесте последней доступной темы. | Следующая тема недоступна, ошибка "для перехода к новой теме требуется выполнить все задания {список не пройденного}" | Состояние не меняется |
| Ученик пытается открыть новую тему после отклонения задачи из более ранней темы. | Следующая тема недоступна, ошибка "для перехода к новой теме требуется выполнить все задания {список не пройденного}" | Состояние не меняется |
| Ученик возвращается в уже открытую тему после отклонения задачи из более ранней темы. | Доступен материал, задачи и тест | Указатель устанавливается на первую задачу в статусе «НЕ РЕШЕНА», если такая есть |
| Ученик вернулся к более ранней теме и пытается открыть новую, пока тест темы непосредственно перед новой ещё не пройден. | Тема недоступна. Ошибка "для перехода к новой теме требуется выполнить все задания {список не пройденного}" | Статус не меняется |

## Ученики и сводки ментора

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Ментор открывает список своих учеников. | Показывается список учеников с идентификаторами | Статус не меняется |
| Ментор выбирает ученика из списка и запрашивает его прогресс. | Показывается список пройденных тем и лучший процент правильных ответов для каждой из них, где есть тест. Показывается список задач на проверке. Ментор может тут же выбрать задачу и перейти к проверке | Статус не меняется |
| Ментор запрашивает прогресс своего ученика по никнейму. | Показывается список пройденных тем и лучший процент правильных ответов для каждой из них, где есть тест. Показывается список задач на проверке. Ментор может тут же выбрать задачу и перейти к проверке | Статус не меняется |
| Ментор ищет по неизвестному никнейму или по никнейму чужого ученика. | Ошибка "Ученик с таким идентификатором не найден" | Статус не меняется |
| Ментор задаёт несколько времён получения сводки в день. | Сообщение, что время получения сводки принято | Время получения сводки записывается в БД. Фоновый процесс проверяет наступление времени для отправки сообщения со сводкой |
| Наступает время сводки, и у ментора есть работы на проверке, включая работы из прошлой сводки. | Ментору присылается сообщение, что есть задачи на проверке, список задач, возможность пройтись по ним | Статус не меняется |
| Наступает время сводки, но работ на проверке нет. | Ничего не происходит | Статус не меняется |

## Запрос помощи

| Действие | Что возвращается | Как изменилось состояние |
| --- | --- | --- |
| Ученик с активным доступом впервые за последний час просит помощи у ментора. | Ученику сообщается, что запрос принят, ментор свяжется. Ментору приходит сообщение, что опреденный ученик присит связаться | Сообщение от ученика отправляется ментору, в базу сохраняется дата и время последнего запроса |
| Ученик повторно просит помощи до истечения часа с предыдущего запроса. | Ученику сообщается, что запрос уже был отправлен. Ментору ничего не приходит. | Состояние не меняется |
