# Контракт Go-компонента

По сути здесь дополнительная проработка требований вместе с контрактами. Там, где используется ID, изначально предполагалась кнопка рядом с определёнными данными. Например, в списке учеников рядом с каждым учеником была бы кнопка получения прогресса.

Начинаем с более простого варианта в виде слэш-команд. Бот указывает ID в сообщении, а пользователь передаёт его в тексте запроса. Бот проверяет переданный ID и возвращает ошибку, если проверка не пройдена. Эта ошибка отдельно в моделях ответа ниже не перечислена.

## Возможные запросы ментора

| Запрос | Данные в запросе | Модель ответа |
| --- | --- | --- |
| Старт бота | Telegram-пользователь | Сессия / ошибка «пользователь не зарегистрирован» с числовым Telegram ID отправителя. При первом запуске без настроенных менторов этот ID можно узнать из ответа бота и добавить в список менторов |
| Получить список студентов | — | Список студентов |
| Получить прогресс студента | Ник или ID студента | Прогресс студента / ошибка |
| Получить список работ студента на проверке | Ник или ID студента | Для каждой отправки — ID отправки, задача и студент |
| Открыть работу на проверку | ID отправки | Сведения об отправке и исходный код присланного файла |
| Принять или отклонить работу | ID отправки, решение ментора, комментарий (обязателен при отклонении) | ОК / ошибка при отклонении без комментария / ошибка, если отправка уже проверена |
| Сгенерировать ссылку-приглашение | — | Ссылка-приглашение |
| Открыть настройку времени получения оповещения о выполненных заданиях | — | Список настроенного времени |
| Добавить время получения оповещения | Время | ОК / ошибка «время уже добавлено» |
| Удалить время получения оповещения | ID времени | ОК |
| Отключить ученика | ID ученика, комментарий | ОК |

Повторная сдача получает собственный ID отправки. Если ментор повторит команду для уже проверенной отправки, прежнее решение сохраняется, а новая отправка остаётся доступной для отдельной проверки.

## Возможные запросы студента

| Запрос | Данные в запросе | Модель ответа |
| --- | --- | --- |
| Войти по ссылке-приглашению | ID из ссылки | Информация о менторе / ошибка «уже зарегистрирован» / ошибка «невалидная ссылка» |
| Получить теорию по теме | ID темы | Ссылка на теорию / ошибка «тема недоступна» с перечнем невыполненных условий |
| Получить список задач по теме | ID темы | Список задач / ошибка «тема недоступна» |
| Получить задачу | ID задачи | Текст задачи / ошибка «тема недоступна» |
| Отправить решение задачи | ID задачи, содержимое прикреплённого файла | Сведения об отправке в статусе «НА ТЕСТИРОВАНИИ» / ошибка, если статус задачи не допускает сдачу |
| Пройти тест | ID темы | Вопрос / ошибка «тема недоступна» |
| Ответить на вопрос | ID вопроса, ID ответа | Следующий вопрос / результат прохождения теста |
| Запросить помощь | Комментарий | ОК / ошибка «запрос уже был отправлен» |

`SubmitSolution` принимает вложение до проверки его формата. Если файл не подходит, автопроверка возвращает задачу в статус «НЕ РЕШЕНА», и ученик получает результат проверки.

При попытке открыть закрытую тему `OpenTopic` возвращает ошибку с перечнем всех условий, которые ученику ещё предстоит выполнить. Для каждой задачи, блокирующей переход, ошибка указывает конкретную задачу. Для непройденного теста или неполученной ссылки на теорию она указывает соответствующую тему. Вызывающий код получает эти сведения в структурированном виде и использует их для сообщения ученику.

## Возможные сообщения

| Получатель | Сообщение | Данные |
| --- | --- | --- |
| Ментор | Пришёл запрос от ученика | Студент, комментарий |
| Ментор | Список работ на проверку | Для каждой отправки — ID отправки, задача и студент |
| Ученик | Пришёл результат автопроверки задачи | Задача с актуальным статусом, результат |
| Ученик | Открылась следующая тема | ID и название открывшейся темы. Бот отправляет отдельное сообщение при первом открытии темы для ученика |
| Ученик | Пришёл результат проверки задачи ментором | Задача с актуальным статусом, комментарий |
| Ученик | Ученик был отключён от программы | Сообщение |
