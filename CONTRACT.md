# Контракт Go-компонента

По сути здесь дополнительная проработка требований вместе с контрактами. Там, где используется ID, изначально предполагалась кнопка рядом с определёнными данными. Например, в списке учеников рядом с каждым учеником была бы кнопка получения прогресса.

Начинаем с более простого варианта в виде слэш-команд. Бот указывает ID в сообщении, а пользователь передаёт его в тексте запроса. Бот проверяет переданный ID и возвращает ошибку, если проверка не пройдена. Эта ошибка отдельно в моделях ответа ниже не перечислена.

## Возможные запросы ментора

| Запрос | Данные в запросе | Модель ответа |
| --- | --- | --- |
| Старт бота | Telegram-пользователь | ОК / ошибка «пользователь с id не найден» |
| Получить список студентов | — | Список студентов |
| Получить прогресс студента | Ник или ID студента | Прогресс студента / ошибка |
| Получить список задач студента на проверке | Ник или ID студента | Список задач |
| Получить задачу по ID | ID задачи | Текст задачи |
| Вынести решение по задаче | Готово или не готово, комментарий | ОК / ошибка «требуется комментарий» |
| Сгенерировать ссылку-приглашение | — | Ссылка-приглашение |
| Открыть настройку времени получения оповещения о выполненных заданиях | — | Список настроенного времени |
| Добавить время получения оповещения | Время | ОК / ошибка «время уже добавлено» |
| Удалить время получения оповещения | ID времени | ОК |
| Отключить ученика | ID ученика, комментарий | ОК |

## Возможные запросы студента

| Запрос | Данные в запросе | Модель ответа |
| --- | --- | --- |
| Войти по ссылке-приглашению | ID из ссылки | Информация о менторе / ошибка «уже зарегистрирован» / ошибка «невалидная ссылка» |
| Получить теорию по теме | ID темы | Ссылка на теорию / ошибка «тема недоступна» |
| Получить список задач по теме | ID темы | Список задач / ошибка «тема недоступна» |
| Получить задачу | ID задачи | Текст задачи / ошибка «тема недоступна» |
| Отправить решение задачи | ID задачи, файл с решением | ОК / ошибка «можно отправлять только не решенные задачи» |
| Пройти тест | ID темы | Вопрос / ошибка «тема недоступна» |
| Ответить на вопрос | ID вопроса, ID ответа | Следующий вопрос / результат прохождения теста |
| Запросить помощь | Комментарий | ОК / ошибка «запрос уже был отправлен» |

## Возможные сообщения

| Получатель | Сообщение | Данные |
| --- | --- | --- |
| Ментор | Пришёл запрос от ученика | Студент, комментарий |
| Ментор | Список задач на проверку | Список студентов, список задач |
| Ученик | Пришёл результат автопроверки задачи | Задача с актуальным статусом, результат |
| Ученик | Пришёл результат проверки задачи ментором | Задача с актуальным статусом, комментарий |
| Ученик | Ученик был отключён от программы | Сообщение |
